## Overview

KopiKu Apps is a coffee shop administration dashboard designed to centralize content and operational management in one web application.

The application provides an administrative interface for managing coffee shop information and monitoring data through a structured dashboard.

## Features

- **Dashboard** — Overview of application data and statistics.
- **Menu Management** — Interface for managing coffee shop menu items.
- **Content Management** — Pages for articles, FAQs, testimonials, and gallery content.
- **Team & Careers** — Interfaces for team information and job listings.
- **Booking & Contact** — Pages for managing booking and contact information.
- **User & Profile** — User-related pages and profile management.
- **Data Visualization** — Charts and visual summaries using Recharts.

*Feature availability depends on the current implementation and backend configuration.*

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/devbyilham/proyek-uas.git
   ```

2. Navigate to the project directory:

   ```bash
   cd proyek-uas
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

Run the production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
