## Overview

KopiKu Apps is a web application developed to provide a centralized interface for coffee shop administration.

The application brings together various management pages in one place, with a focus on usability, organized content, and a consistent user interface.

## Features

- **Dashboard** — Overview of application data and statistics.
- **Menu Management** — Interface for managing coffee shop menu items.
- **Article Management** — Manage coffee shop articles and content.
- **FAQ Management** — Organize frequently asked questions.
- **Team Management** — Display and manage team information.
- **Careers** — Manage job listings.
- **Testimonials** — Manage customer testimonials.
- **Booking & Contact** — Pages for booking and contact information.
- **User & Profile** — User-related pages and profile information.
- **Gallery** — Display coffee shop images and visual content.
- **Data Visualization** — Present data through charts and visual summaries.

*Features may depend on the current implementation and backend configuration.*

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/devbyilham/kopiku-apps.git
   ```

2. Navigate to the project directory:

   ```bash
   cd kopiku-apps
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
